# BotMod — Minecraft 1.21.4 / Fabric

Wymagania: Java 21, Gradle i Fabric Loom.

## Budowanie
Uruchom w katalogu projektu:
- Windows: `gradlew.bat build`
- Linux/macOS: `./gradlew build`

Gotowy JAR pojawi się w `build/libs/`.

## Używanie
Uruchom świat z modem i naciśnij `O`. Boty są NPC typu mob z logiką podążania, a nie pełnoprawnymi fake-playerami.

Uwaga: to projekt źródłowy i może wymagać drobnych dostosowań API przy innej wersji Loom/Fabric.
